# EFT Allergy Tracker

Mobile-first PWA companion for the seasonal **Allergic** modifier in Escape from Tarkov.

The tracker is designed for one fast raid-time action: find a consumable and mark it as safe or allergic. Progress is stored locally on the device and remains available offline once the PWA is installed.

## Planned v0.1

- food and medical item catalog
- search and category filters
- `unknown`, `safe`, `allergic` statuses
- allergy counter (`0 / 3`)
- local persistence
- mobile-first UI
- offline-capable PWA
- GitHub Pages deployment

## Stack

- React
- TypeScript
- Vite
- vite-plugin-pwa
- localStorage
- GitHub Actions + GitHub Pages
